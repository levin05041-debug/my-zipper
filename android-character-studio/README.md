# סטודיו לאנימציית דמות – Android

פרויקט Kivy בסיסי בעברית. כולל מסך תצוגה, כפתורי פעולות והפעלת רצף פריימים.

## הוספת תמונות ההליכה
יש להוסיף את שמונת קובצי ה-PNG לתיקייה:
`android-character-studio/assets/walk/`
בשמות `walk_01.png` עד `walk_08.png`.

## בניית APK
המאגר כולל GitHub Actions. לאחר העלאת הקבצים, פתחו Actions והפעילו את
Build Android APK. בסיום מורידים את artifact בשם character-studio-debug-apk.

הערה: רק הליכה תעבוד לאחר הוספת הפריימים. שאר הפעולות הן כפתורי ממשק בלבד.
יצירת אנימציות AI אינה מחוברת בגרסה זו.
