# סטודיו אנימציה לדמות – Android

אפליקציית Android בסיסית להצגת אנימציית דמות מתמונות פריימים:
- טעינת כמה תמונות PNG/JPG מהטלפון
- ניגון רציף, עצירה, מעבר לפריים הבא/הקודם
- שליטה במהירות 2–24 פריימים לשנייה
- כפתורי מצבי תנועה: הליכה, ריצה, קפיצה, אגרוף, בעיטה וכריעה

## בניית APK
במאגר הראשי פתח Actions → Build Android APK → Run workflow. בסיום, הורד את ה-artifact בשם character-animation-studio-apk.

הערה: כפתורי סוגי התנועה הם בחירת מצב בלבד. כדי לנגן כל תנועה יש לטעון את תמונות הפריימים המתאימות. האפליקציה אינה מייצרת תנועות AI בעצמה.
